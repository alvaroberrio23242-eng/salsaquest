
# 💃 SalsaQuest — La Ruta Salsera de Medellín

Plataforma cultural e interactiva dedicada a explorar la historia, lugares emblemáticos, artistas, sellos discográficos y emisoras que definen la cultura salsera de Medellín.

## 🚀 Características
- Ruta Salsera: Directorio verificado de bares, discotecas y sitios históricos.
- Línea del Tiempo: Recorrido histórico de la salsa en Medellín.
- Plurilingüe: Soporte estructurado para internacionalización (Español, Inglés, Francés).
- Producción Lista: Totalmente optimizado para despliegue en la nube (Render) con PostgreSQL.

## 🛠️ Instalación y Configuración Local

1. Clonar repositorio:
   git clone https://github.com/alvaroberrio23242-eng/salsaquest.git
   cd salsaquest

2. Crear y activar entorno virtual:
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

3. Instalar dependencias:
   pip install -r requirements.txt

4. Ejecutar Pruebas:
   python -m pytest

5. Iniciar Servidor Local:
   python run.py
