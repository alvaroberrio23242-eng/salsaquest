# 🕺 SalsaQuest

**SalsaQuest** es una aplicación web interactiva diseñada para turistas que visitan lugares emblemáticos de la cultura salsera (como *Son Havana*). La plataforma combina narración de historias (storytelling), juegos y módulos interactivos para enseñar sobre la historia, el menú, la música y la etiqueta de la salsa de una forma accesible y entretenida.

---

## 🌟 Características Principales

- 🌐 **Plataforma Multilingüe:** Traducción y contenido accesible para turistas internacionales.
- 📜 **Menú e Interacción:** Consulta interactiva de productos, bebidas y gastronomía del establecimiento.
- 🎵 **Cultura & Storytelling:** Módulos educativos sobre la historia de la salsa y sus exponentes.
- 🔐 **Gestión de Usuarios:** Sistema de registro e inicio de sesión (*Authentication*).
- 📅 **Eventos & Cartelera:** Sección informativa con las actividades y presentaciones del lugar.

---

## 🛠️ Tecnologías Utilizadas

- **Backend:** Python / Flask
- **Base de Datos:** SQLite / SQLAlchemy
- **Frontend:** HTML5, CSS3, JavaScript
- **Control de Versiones:** Git & GitHub
