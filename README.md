# SalsaQuest 🎺

## Learn Salsa. Play Culture. Live Medellín.

SalsaQuest es una aplicación web interactiva que enseña la cultura de la salsa mediante juegos, historias, logros y experiencias inmersivas.

## Objetivo

Crear la mejor aplicación web para que un turista descubra y aprenda la cultura de la salsa de forma interactiva.

## Tecnologías

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
